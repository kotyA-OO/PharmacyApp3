# Аптека «Здоровье+»

Информационная система для автоматизации работы аптеки. 
Разработана в рамках учебной практики УП.04 (Кейс-задача №2-6).

## Технологии
- Язык: C# (Windows Forms)
- База данных: MySQL 8.0
- Среда разработки: Visual Studio
- Автоматизация: GitHub Actions

## Роли пользователей
1. **Администратор** — полный доступ (добавление, удаление, изменение лекарств).
2. **Провизор** — изменение только количества товара.
3. **Клиент** — просмотр каталога лекарств (только чтение).

## Как запустить
1. Установить MySQL Server 8.0.
2. Выполнить SQL-скрипт из файла `database.sql` для создания базы `pharmacy_db`.
3. Открыть решение `PharmacyApp3.slnx` в Visual Studio.
4. Запустить проект (F5).
